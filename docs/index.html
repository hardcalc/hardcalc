The file is the document

A hardcalc file is valid Markdown. Any viewer shows the headings, text and tables; hardcalc also reads the types, formulas, layers and charts kept in fenced blocks. A plain Markdown table is already a valid matrix.

Euro   = decimal(2) unit "€"
Status = enum(open, paid, cancelled)

What it does

Keyboard first, with full mouse support. Runs on macOS, Linux and Windows.

Vectors, matrices, tensors

Every table has a shape. Tensors have named axes and turn into a pivot view; slices and scenarios stack levels on a table.

Types with units

Base types and your own, like Euro = decimal(2) unit "€". Units are checked when calculating: € + m is an error.

Layers

As in CAD, formatting, validation rules, comments and formula highlighting live on layers you can show, hide and edit one at a time.

Formulas you know

Excel functions like sumif and xlookup, references by name, footer rows, and your own functions like LAMBDA.

Reports

Charts, running text with live values, grid layouts with page breaks, printing and PDF – all from the same file.

Calculation sheets

Engineering calculations with units, named variables and the way to the result, typeset as a PDF report through Typst.

Works with what you have

Import and export xlsx, xls, ods and CSV. A LibreOffice extension opens .hcmd files directly in Calc and saves them back without touching anything Calc does not know. Install it with hardcalc libreoffice install, or download the .oxt file from the release.

hardconf – TOML with a built-in schema

The second program edits TOML configuration files. A schema in a comment block at the end of the file brings types, defaults, choices and documentation; the file stays plain TOML.
